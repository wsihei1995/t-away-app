# 天水圍人車隊 T-AWAY

## 檔案
- `index.html`：客人外賣前台
- `admin.html`：餐廳、菜單及付款設定管理後台

## 後台登入
- 打開 `admin.html`
- 示範 PIN：`8888`
- 可新增、修改、刪除餐廳
- 可修改分類、地區、配送費、營業狀態、餐點及價格
- 可修改支付寶、微信支付及轉數快的商戶資料／備註

## 付款功能狀態
前台已加入支付寶、微信支付、轉數快三種付款選項，以及送餐地址、電話、備註和訂單確認流程。現階段是可操作流程示範，未會真正扣款。

要正式收款，需要：
1. 申請相應支付商戶帳戶
2. 由後端安全保存商戶密鑰，不能直接放在前台 HTML
3. 接入支付平台 API、付款回調及訂單核對

## 注意
目前是可操作示範版，資料儲存在同一部手機／瀏覽器的本機儲存空間。正式上線時，需再接雲端資料庫及正式管理員登入，讓資料可以跨手機同步。

## 使用方法
用瀏覽器開啟 `index.html` 看客人前台；用瀏覽器開啟 `admin.html` 管理餐廳資料。儲存後，重新整理前台即可看到更新。
